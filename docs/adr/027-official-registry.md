# ADR 027: Official registry lists the GHCR image

A release pushes `ghcr.io/aiveto/veto`. The image label `io.modelcontextprotocol.server.name` is `io.github.aiveto/veto`. `server.json` names that server and that OCI identifier. `mcp-publisher` publishes on the tag.

Refused: Docker Hub. MCPB. Retagging v0.1.3.
